# AI Convergence Lab (AI융합실험실)

Website of the AI Convergence Lab, Department of AI Convergence, Kunsan National University, led by Professor Han-Gue Jo.

Live site: https://ai-convergence-lab.github.io/

## Editing
- All content is in `index.html`.
- Photos live in `images/` (WebP format keeps the site fast).
- To add a member photo, put the file in `images/` and replace the initials inside that person's `.avatar` with `<img src="images/name.webp" alt="Name">`.
